# ADR-0007：图片存储使用阿里云 OSS 服务端签名直传

- 状态：已接受
- 日期：2026-09-14

## 背景

用户发帖需要上传图片。可选方案有：后端中转上传、前端直传（服务端签名）、STS 临时凭证直传。

## 决策

采用**服务端签名直传**：

1. 前端调用 `GET /api/oss/signature`（需登录）获取 `policy` 与 `signature`
2. 前端 POST 表单**直传 OSS**，不经过后端服务器
3. OSS 回调 `POST /api/oss/callback`，后端**验签**后写入 `post_image` 表

## 理由

1. AccessKey **永不落到前端**，可规避 APK 被反编译导致的密钥泄露（APK 必然可被反编译）。
2. 直传不占用后端带宽与内存 —— 这对 2 vCPU / 2 GiB 的服务器尤其重要。
3. 相比 STS 临时凭证，签名直传实现更简单，且项目当前只传图片（单图 ≤ 5MB），无需分片与断点续传。
4. 若将来需要传视频，再引入 STS 方案，届时接口不变，只扩展签名内容。

## 后果

- 必须配置 OSS 的 CORS 允许站点域名。
- 回调接口必须严格验签，并校验文件类型与大小。
- 提交帖子时，后端必须校验图片 URL **归属本项目的 OSS 目录前缀**，防止用户提交外部恶意链接。
- 缩略图使用 OSS 图片处理参数生成，列表页只加载缩略图。
- 必须配置防盗链（Referer 白名单）与流量告警。
