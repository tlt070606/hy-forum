# ADR-0003：交付形态为网站 + WebView 壳 APK，不做微信小程序

- 状态：已接受
- 日期：2026-09-14

## 背景

需求方最初要求「小程序 + 网页 + 安卓」三端，后明确放弃小程序。

## 决策

- **主形态**：网站（Vue 3 SPA + PWA）
- **安卓端**：Android WebView 壳，加载线上站点地址
- **不做**：微信小程序

## 理由

1. 网站主体为**个人主体**，无法开通阿里云短信服务与微信开放平台网站登录，做小程序也会卡在类目与内容审核上。
2. 交付形态收敛为两种后，前端可完全使用 Web 栈，不再迁就小程序组件与 API 限制。
3. PWA 可让用户「添加到主屏幕」，以接近零的成本获得 App 般的使用体验。

## 后果

- WebView 壳需额外实现：拦截网盘域名并交给系统浏览器 / 对应 App、处理物理返回键、启动页避免白屏。
- 加载的是 HTTPS 站点，**无需**开启 `usesCleartextTraffic`；调试期若用 HTTP 需临时开启并在上线前关闭。
- 壳工程中不得硬编码任何密钥或接口凭证（APK 可被反编译）。
