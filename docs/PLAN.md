## 2. 已确认口径（需求方明确答复）

1. 产品为论坛，名称「Hy论坛」；原资料分享功能**融合**为「资源分享版块」。
2. 首页提供「我关注的人」与「全部」**双流**。
3. 帖子形态为**贴吧式**：有版块、有标题；评论为主楼 + 楼中楼**两层**。
4. **不做微信小程序**；交付**网站 + 安卓 APK**。
5. 注册使用**用户名 + 密码 + 图形验证码**，**不使用短信验证码**（个人主体无法开通阿里云短信服务）。注册模式后台可配（`open` / `invite` / `closed`）。
6. 原「中学区 / 大学区 / 社会区」**不保留**，版块重新设计。
7. **收藏**与**消息通知**本期实现。
8. **邮箱找回密码不做**（`user.email` 字段保留备用）。
9. 数据规模：帖子**存量**目标 1000 条，长期上限 1 万条；内容由用户发帖**自然累积**，**不做预置导入**。
10. 服务器：阿里云 **2 vCPU / 2 GiB**、Ubuntu 22.04、ESSD 40 GiB、到期 2027-01-06。
11. ~~服务器**暂不升配**（成本原因），因此必须具备低配兼容方案。~~ **已废止（2026-09-14，D4 决策）**：改为**开发期以本地为基准、上线时先升配**，并**取消部署档位机制**（只保留一份 compose 与一份参数）。原 2C2G 的参数核算**未丢弃**，转为 [`ops/deployment.md`](ops/deployment.md) 附录 A「应急参数集」。决策依据见 [`review/2026-09-14-方案评审记录.md`](review/2026-09-14-方案评审记录.md) §10 D4 与 [`adr/0010-部署以本地开发为基准并取消档位.md`](adr/0010-部署以本地开发为基准并取消档位.md)。
12. 接受「论坛社区备案受阻 → 切换为邀请制 / 不公开推广」的降级方案。
13. 内容审核认可「接口抽象 + 默认自建实现」，不阻塞于第三方服务资质。

## 4. 里程碑与验收标准

| 阶段 | 内容 | 交付物 | 验收标准 |
|---|---|---|---|
| **M0** | 数据库地基 | `docs/db/schema.sql`（**16 张表** + 索引 + 1 个 CHECK 约束）、`docs/db/migrations/`（增量脚本）、`docs/db/seed.sql`（管理员、7 个版块、默认配置项；**敏感词库为占位，需另行导入真实词库**）、`scripts/verify_m0.ps1`（验收脚本） | ① 在 MySQL 8.0.16+ 中一次执行成功，无报错；② **`powershell -File scripts/verify_m0.ps1 -Init` 全部检查项 PASS**（含"非法 `parent_id`/`root_id` 组合被 CHECK 拒绝"这条实证） |
| **M1** | 后端骨架 + 用户体系 | Spring Boot 工程、统一响应 / 异常处理、Sa-Token、注册 / 登录 / 图形验证码、注册模式 | Knife4j 中可完成注册 → 登录 → 获取 `/api/user/me`；切换注册模式后行为同步变化 |
| **M2** | 前端骨架 + 登录注册 | Vue3 + Vant 工程、路由、Axios 封装、布局、登录注册页 | 浏览器中可完成注册与登录，token 正确携带 |
| **M3** | 版块 + 帖子 + OSS | 版块列表、发帖、帖子列表、详情、九宫格、网盘卡片、直传签名与回调 | 可从零发布一条带图资源帖并在详情页正确展示与复制 |
| **M4** | 评论 + 点赞 + 收藏 + 关注 + 主页 | 楼中楼评论、帖子 / 评论点赞、收藏、关注、个人主页、首页双流 | 双流正确过滤；楼中楼不超过两层；重复点赞不产生脏数据；收藏／取消收藏幂等，且「我的收藏」列表与 `post.collect_count` 一致 |
| **M5** | 内容安全 + 消息通知 | 敏感词过滤、举报、后台审核队列（**帖子 + 评论**）、`ContentAuditService` 抽象、消息通知 | 含敏感词的**帖子与评论**均进入待审且前台不可见，**且两者都能在后台放行或屏蔽**（评论入口 `PUT /api/admin/comments/{id}/status`）；编辑帖子后自动重新进入待审；被点赞或评论的用户能收到通知 |
| **M6** | 管理后台 | 独立前端工程 + 全部管理接口 + 系统配置与邀请码管理 | 管理员可审核帖子、处理举报、封禁用户、维护版块与敏感词、切换注册模式、生成邀请码；**且上述每个动作均可在 `admin_operation_log` 中追溯**（操作人／时间／对象／动作／理由），保留 ≥ 6 个月 |
| **M7** | 安卓端 | Kotlin WebView 壳工程 + 签名 APK | 真机安装后正常浏览；网盘链接跳转外部浏览器；返回键行为正确 |
| **M8** | 上线 | 单一 `docker-compose.yml`（**无档位**）、Nginx 配置、HTTPS、备案完成、备份脚本 | 公网域名可 HTTPS 访问；**上线前已回填目标服务器规格并按 [`ops/deployment.md`](ops/deployment.md) §6 复算参数**；备份任务按计划执行且**验证过恢复** |

**并行事项**：域名注册、ICP 备案、网信部门论坛社区备案咨询，**自 M0 起并行启动**，不阻塞开发。

## 5. 风险登记册

| # | 风险 | 概率 | 影响 | 应对措施 |
|---|---|---|---|---|
| R1 | ICP 备案周期长（7–20 工作日） | 高 | 中 | 尽早启动；开发期用服务器 IP + 关闭域名校验调试 |
| R2 | 论坛社区备案（网信）办理受阻 | 中 | 高 | 提前咨询当地网信部门；已备降级方案为邀请制 / 不公开推广。**注意：该降级属于「残余风险接受」，不构成法定豁免**（见 [`技术方案.md`](技术方案.md) §10） |
| R3 | 机器人注册 / 灌水 | 高 | 中 | 图形验证码 + 发帖频率限制 + 关键词拦截 + 管理员封禁 |
| R4 | 用户发布违法违规内容 | 中 | 高 | 敏感词过滤 + 举报 + 审核队列 + 留存日志 |
| R5 | 计数字段不一致 | 中 | 低 | 同事务增减 + 定期校准任务 |
| R6 | OSS 流量费用超预期 | 中 | 中 | 图片压缩 + 缩略图 + CDN + 流量告警与防盗链 |
| R7 | AccessKey 泄露 | 低 | 高 | 仅服务端持有；前端只用签名；RAM 子账号最小授权 |
| R8 | 网盘链接失效 | 高 | 中 | 详情页提供「链接失效上报」入口 |
| R9 | 数据库误删 / 损坏 | 低 | 高 | 每日备份至 OSS，保留 7 天，定期演练恢复 |
| R10 | 需求持续变更导致返工 | 高 | 中 | 每个里程碑结束后确认再进入下一阶段 |
| R11 | 前端 SPA 不利 SEO | 高 | 低 | 本期接受；如需 SEO 再迁移 Nuxt3 SSR |
| R12 | 内容量增长超出预期（1000 → 1 万 → 更高） | 中 | 中 | 1 万条内 `LIKE` 可用；突破 1 万条切换 `FULLTEXT ngram`；突破 10 万条引入独立搜索服务 |
| R13 | 论坛冷启动期内容稀缺（内容靠用户自然累积） | 中 | 高 | **属运营问题**；管理员持续产出内容、引导核心用户、用邀请制控制早期质量 |
| R14 | 目标服务器内存不足导致 OOM（若最终规格偏低） | 中 | 高 | **上线前回填规格并按 [`ops/deployment.md`](ops/deployment.md) §6 复算参数**；若最终规格仍为 2 GiB，必须整体启用该文档**附录 A**（含 2G swap、容器上限、`memswap_limit == mem_limit`）；并准备升配预案 |
| R15 | 在 2G 服务器上执行构建导致构建期 OOM | **高** | 高 | **硬性禁止**在服务器上构建；一律本地或 CI 构建后上传产物 |
