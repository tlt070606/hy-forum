## 2. 小程序包构建方式（复现）

```bash
cd web
npm run build:mp-weixin          # 产物：web/dist/build/mp-weixin/
# 导入：微信开发者工具 → 导入项目 → 目录选 dist/build/mp-weixin → appid 用测试号
# ⚠️ 必须勾选"不校验合法域名"（C2 硬约束：request 只允许已备案 HTTPS 域名，
#    本站无域名，练习环境必须关闭校验，见 ADR-0011）
```

## 3. 导入后的最小验证清单（人工，约 10 分钟）

1. 首页双流加载（最新 / 关注）；
2. 注册 → 登录（图形验证码在小程序端的显示与输入）；
3. 发一帖（带图走 OSS 直传；**小程序端图片上传若失败，检查 C2 域名约束是否漏关**）；
4. 网盘卡片：点"复制链接"应弹"已复制，请到网盘 App 粘贴打开"——**不得出现"点击打开"文案**（技术方案 §12 的平台差异表）；
5. 返回键退出行为（技术方案 §12 第 3 条）。
