# Hy论坛 交接说明

> **这份文件是干什么的**：给你或另一个 Agent 一份**能直接上手**的东西。
> 它只做三件事：**怎么把项目跑起来**、**东西都在哪**、**有什么坑**。
>
> 项目事实的**唯一来源仍然是 [`docs/`](README.md)**（铁律 1）。本文件内联的只有「可执行的操作步骤」——
> 命令、URL、路径这类能立刻验证的东西；凡是"项目是什么样"的描述，一律给指针，不复制。
> **为什么坚持不复制**：本项目的 `技术方案.md` §13–§15 曾经是 `PLAN.md` 的副本，半年内漂移了 6 处，
> 后来整段删掉才修好。副本必然漂移，而漂移的副本比没有副本更危险。

### 2.2 起后端（三条命令）

```powershell
# ① 每个新会话/新终端的第一件事 —— 不设这条，Maven 会用错 JDK 编译
$env:JAVA_HOME='D:\develop\jdk21'

# ② 打包（首次，或改了后端代码之后）
cd D:\demo\Hy论坛\server
mvn clean package -DskipTests

# ③ 起应用 —— 参数必须整体加引号，否则 PowerShell 会把它拆成主类名
cd D:\demo\Hy论坛
java '-Dstdout.encoding=UTF-8' -jar server\target\hy-forum-server-0.0.1-SNAPSHOT.jar
```

**这个窗口要一直开着**（它就是后端）。看到日志里 Tomcat 起来后，另开一个窗口做下面的事。

### 2.3 管理员账号（后台登录用）

```
账号 admin
口令 HhkUjhcYPBkQdFSM      ← 首次登录后请改掉；明文不在仓库里，只存了 BCrypt 哈希
```

要换口令就自己生成一份（用后端同一个 encoder，会自校验）：

```powershell
cd D:\demo\Hy论坛\server
mvn -q dependency:build-classpath '-Dmdep.outputFile=target/cp.txt'
cd ..
java -cp (Get-Content server/target/cp.txt -Raw) scripts\GenBcryptHash.java '你的新口令'
# 把输出的哈希替换进 docs/db/seed.sql，并 UPDATE 已存在的 admin 行
```

## 3. 接口文档到底在哪

**三处，各有各的用途。找不到的时候照这个顺序看：**

### 3.1 可视化调试（最直观）—— 需要后端先跑起来

```
http://localhost:8080/swagger-ui/index.html
```

> **⚠️ 打不开的话，99% 是后端没在跑** —— 它不是静态页面，是应用启动后才提供的。
> 先执行 §2.2 的第 ③ 条，再刷新浏览器。
> 已实测：页面及其全部 JS/CSS 资源都返回 200（`swagger-ui-bundle.js` 1.37 MB），能正常渲染。

### 3.2 机器可读的契约（**唯一事实来源**）

```
openapi.json          ← 仓库根目录，不是 docs/ 里
```

8 个路径：`/api/auth/{captcha,register,login,logout,register-mode}`、`/api/user/me`、`/api/admin/{login,logout}`。

- **前端的类型应该从它生成**，不要手写。
- **不要手工编辑它** —— 它由后端注解导出、由 L1 冻结。
- 后端注解改了要重新导出：
  ```powershell
  powershell -File scripts/export_openapi.ps1        # 加 -SkipBuild 可复用已有 jar
  ```

### 3.3 人类可读的说明

## 5. 红线（不改就会出事）

1. **没设 `JAVA_HOME`** → Maven 报 `invalid target release`（看着像代码问题，其实是环境）
2. **改了 `.ps1` 没补 BOM** → PowerShell 5.1 按 GBK 解读，中文乱码**且解析失败**。**文件写入工具会丢 BOM**
3. **手工改契约**（`db/schema.sql` 或 `openapi.json`）→ 其他人基于旧契约继续做，漂移无法察觉。契约不足就**提 CR**，别自己加
4. **在服务器上构建** → `mvn package` / `npm run build` 峰值超 1G，2 GiB 机器会 OOM（铁律 6）
5. **前端持有 AccessKey** → 上传一律走 **OSS 服务端签名直传**（铁律 5、8）。打包产物同样可被反编译
6. **停 VM 里的 6379 redis** → 本机 `D:\test\hm-dianping` 会**静默失效**（不报错，只是卡在 `SYN_SENT` 重连）。
   腾 VM 空间时只停 `rabbitmq / seata-server / nacos / nginx / mysql`
7. **测试类用 `*IT.java` 命名** → Surefire **默认不跑它**，测试全绿但从没执行过
8. **没有命令输出的"完成"** → 不算完成。测试要求「红 → 绿」两次输出

## 6. 前端要点（M2 用得上）

技术栈：**uni-app + Vue3 + Vite + TS + wot-design-uni + Pinia**。
选型理由与三条硬约束见 [`adr/0011`](adr/0011-前端改用uni-app作为唯一前端.md)。

1. **契约驱动**：类型从 `openapi.json` 生成，放 `web/src/api/generated/` —— **那个目录由 L1 独占，不要手改生成物**
2. **UI 库是 wot-design-uni**，不是 Vant（Vant 是 Web 组件库，**小程序没有 DOM**，用不了）
3. **路由用 `pages.json`**，不是 Vue Router
4. **请求封装 `uni.request`**，不是 Axios（小程序没有 XHR）。统一处理 `Authorization` 头、`{code,message,data}`、错误码→文案
5. **平台差异只有三处**：本地存储、请求、跳转外部链接。**集中封装**，别让 `#ifdef` 散落 —— 散落就分叉
6. **token 用封装过的存储模块**，不要直接 `localStorage`（小程序端没有）
7. **注册模式动态渲染**：先查 `GET /api/auth/register-mode`，只有 `invite` 才显示邀请码输入框
8. **验证码是 base64 图片**，两端同一套代码
9. **网盘链接在小程序端只能复制，跳不了外部浏览器**（没有 `web-view`）。M2 还不涉及，文案先记住
10. **小程序端永远只能练习**：个人主体不支持 `web-view`、`request` 只允许已备案域名、类目禁论坛。
    **不要按"将来能上线"投入精力**

### H5 能自动化，小程序端只能手工

- **H5**：Playwright 对着真后端跑通（可进 CI）
- **小程序端**：微信开发者工具打开 `dist/build/mp-weixin`，**勾上"不校验合法域名"**，请求指向 `http://127.0.0.1:8080`。
  AppID 用**测试号**即可（不用注册主体）。
